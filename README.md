# Cybercrime Threat Intelligence Dashboard

This project is a cybersecurity analytics dashboard that uses synthetic threat intelligence data to analyze suspicious indicators, assign risk scores, and generate analyst summaries.

## Purpose

The goal of this project is to demonstrate how cybercrime indicators can be collected, categorized, scored, and prepared for investigation workflows without using illegal content, dark web data, or real exploitation material.

## Features

- Synthetic threat indicator dataset
- Python-based risk scoring engine
- Risk classification: Low, Medium, High
- Analyst summary report
- Dashboard-ready CSV output
- Designed for future OpenSearch integration

## Tools

- Python
- CSV
- Docker
- OpenSearch planned
- Dashboard visualization planned

## Safety Note

This project uses only synthetic data. It does not collect, store, view, or analyze illegal material.
